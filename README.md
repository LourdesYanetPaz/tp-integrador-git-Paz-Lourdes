# Diseño web con html y css

## Descripción
Es una página web que trata sobre las tecnologias involucradas en diseño web

## Objetivo
Este repositorio fue realizao para ser presentado en un curso de manejo de git y el proyecto contenido en él fue realizado como una práctica inicial de html y css

## Estructura del repositorio
La carpeta proyecto contiene los archivos correspondientes a la página web. Dentro de esa carpeta se encuentra index.html que contiene toda la informacion de la pagina, styles.css que contiene los estilos y una carpeta llamada img que contiene dentro las imagenes usadas.

El archivo README.md contiene documentación del repositorio y el archivo ENTREGA.md contiene la información solicitada en el curso
