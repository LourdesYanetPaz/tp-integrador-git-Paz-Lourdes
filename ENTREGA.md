## Descripción del proceso
Inicialicé el repositorio local usando git init, vinculé el repositorio remoto haciendo git remote add origin y git remote -v, agregué los primeros archivos al stag con git add ., realicé un commit de los cambios y los subí al repositorio remoto con git push. Cuando realizaba una rama nueva la creaba con git switch -c, realizaba los cambios necesarios y luego las fusionaba con la rama principal. Este proceso se realizó varias veces, siempre verificando en qué rama me encontraba usando git branch y usando pull para aplicar los cambios cuando hice merge pull request desde github.
